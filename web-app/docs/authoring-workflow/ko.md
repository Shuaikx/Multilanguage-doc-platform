# 문서 작성 흐름

명확한 원본 문서는 신뢰할 수 있는 번역의 출발점입니다. 한 언어에서 내용과 구조를 먼저 완성한 다음 다른 언어를 동기화합니다.

## 권장 단계

1. 새 주제의 문서 디렉터리와 세 언어 파일을 만듭니다.
2. 원본 파일 하나에서 제목, 단락, 목록, 링크와 코드 예제를 완성합니다.
3. 원본 파일을 명확히 지정하여 `$sync-doc-translations`를 호출합니다.
4. Parallel Docs에서 두 언어 버전을 나란히 검토합니다.
5. 검증 스크립트를 실행한 뒤 세 파일을 함께 Git에 커밋합니다.

## 변경하지 않을 내용

| 내용 | 예시 |
| --- | --- |
| 명령 | `npm run dev` |
| 파일 이름 | `zh.md` |
| URL | `http://localhost:3000` |
| 코드 블록 | 구문과 식별자를 그대로 유지 |

> 링크 텍스트는 번역하되 링크 대상은 변경하지 마세요.

## 완료 기준

세 버전은 같은 정보를 전달하고 같은 섹션 순서를 사용하며 코드 블록 수와 링크 대상이 같아야 합니다. 번역은 직역하지 말고 대상 언어에 자연스럽게 작성합니다.
