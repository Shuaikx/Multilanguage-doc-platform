# 文档编写流程

一份内容明确的源文档是可靠翻译的起点。先在一种语言中完成内容和结构，再同步其他语言。

## 推荐步骤

1. 为新主题创建文档目录和三个语言文件。
2. 在一个源文件中完成标题、段落、列表、链接和代码示例。
3. 调用 `$sync-doc-translations`，并明确指定源文件。
4. 在 Parallel Docs 中并排检查两个语言版本。
5. 运行校验脚本，再将三个文件一起提交到 Git。

## 保持不变的内容

| 内容 | 示例 |
| --- | --- |
| 命令 | `npm run dev` |
| 文件名 | `zh.md` |
| URL | `http://localhost:3000` |
| 代码块 | 语法和标识符保持原样 |

> 翻译链接文字，但不要更改链接目标。

## 完成标准

三个版本应表达相同的信息、使用相同的章节顺序，并包含相同数量的代码块和链接目标。翻译应自然地符合目标语言习惯，不要逐字硬译。
